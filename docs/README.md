# docs/

Índice geral da documentação do baseline-ui.

- **[positioning.md](./positioning.md)** — o que o projeto promete, e
  onde cada garantia é verificada de verdade. Comece por aqui.
- **[components/](./components/README.md)** — catálogo dos 14
  componentes, **gerado** a partir de `baseline.manifest.json`
  (`npm run docs`) — nunca editado à mão.
- **[decisions/](./decisions/)** — todo ADR (decisão de arquitetura
  permanente, com alternativas rejeitadas).
- **[specs/](./specs/README.md)** — iniciativas transversais em
  andamento, com critério de aceite.
- **[figma/](./figma/mapeamento-figma.md)** — mapeamento de cada
  conceito do sistema pro conceito equivalente no Figma.
- **[roadmap.md](./roadmap.md)** — horizonte de vocabulário de
  componentes (o que entra depois).

Fora de `docs/`: [`AGENTS.md`](../AGENTS.md) (convenções pra agente de
IA), [`CONTRIBUTING.md`](../CONTRIBUTING.md) (processo humano),
[`llms.txt`](../llms.txt) (pontos de entrada curados),
[`CHANGELOG.md`](../CHANGELOG.md) (histórico de versões).
