# Card

**Tipo:** `single` — componente puro, sem motor headless (não há comportamento interativo a herdar).

**Classe CSS:** `bl-card`

## Props

| Nome          | Valores                  | Default | Data-attribute        |
| ------------- | ------------------------ | ------- | --------------------- |
| `padding`     | `none`, `sm`, `md`, `lg` | `md`    | `data-bl-padding`     |
| `interactive` | `true`, `false`          | `false` | `data-bl-interactive` |
